Olá! Sou engenheiro de software no Itaú Unibanco, com quatro anos de experiência em sistemas backend de alta criticidade no setor financeiro. Gosto de acompanhar o caminho completo: do desenho da aplicação até a plataforma que a sustenta em produção.

**Atuação**

- Serviços e APIs em Java com Spring e Quarkus, aplicando Clean Architecture, DDD e testes como parte do design.
- Arquitetura distribuída: mensageria, integrações resilientes e desacoplamento entre domínios.
- Engenharia de plataforma e confiabilidade: workloads em Kubernetes, infraestrutura como código com Terraform e provisionamento em AWS.

**Evolução técnica**

Comecei em aplicações Java e processamento batch; hoje trabalho com microsserviços cloud native, de Spring Boot a Quarkus, e com a plataforma que os opera. O passo atual é Go — na pós-graduação Go Expert (Full Cycle) —, com foco em concorrência, performance e no ecossistema que sustenta ferramentas como Kubernetes, Docker e Terraform.

**Fora do expediente**

Sou daqueles que gostam de abrir o capô das ferramentas do dia a dia: ler internals de Go, montar lab de Kubernetes e quebrar as coisas em ambiente controlado só para entender o porquê. Se quiser trocar ideia sobre arquitetura, backend ou plataforma, me chama no [LinkedIn](https://linkedin.com/in/kaykyfreitas).
